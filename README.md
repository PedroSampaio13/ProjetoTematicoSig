# ProjetoTematicoSIG

Projeto SIG desenvolvido com:
- SvelteKit
- OpenLayers
- FastAPI
- PostgreSQL + PostGIS
- Redis

---

# FrontEnd

## Primeira vez

```bash
cd frontend
npm install
npm run dev
```

## Proximas vezes

```bash
cd frontend
npm run dev
```

# BackEnd
 ## Primeira vez

```bash
cd backend
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Proximas vezes
```bash
cd backend
.venv\Scripts\activate
uvicorn app.main:app --reload
```
